Academic Space Manager

Módulo HTTP REST em FastAPI responsável por inventário físico, cadastro de salas e gerenciamento de restrições docentes.

Endpoints de Inventário

POST /api/v1/rooms, POST /api/v1/rooms/import-csv para cargas em lote transacionais.

Restrições Horárias Docentes

POST e DELETE em /api/v1/allocation/restrictions para cadastro e reset semestral de restrições.
